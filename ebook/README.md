# 考研数学电子书

这是一个本地静态电子书系统，用来把 `typst/` 中的正式章节组织成网页阅读器，并提供目录跳转和关键词搜索。

## 功能

- 自动扫描微积分、线性代数和概率论的正式 Typst 章节；历史归档和公共样式文件不进入电子书目录。
- 生成按学科分组的目录树；点击左侧章节后，会展开该章节内的一级大点子目录。
- 采用两栏布局：左侧目录，右侧电子书阅读界面。
- 子目录显示对应页码，点击后直接跳转到该大点所在页面。
- 搜索框放在阅读区顶部中间，搜索结果以下拉浮层显示，点击结果直接跳转到对应章节页码。
- 网页默认显示由 Typst 以 260 DPI 直渲、再无损压缩为 WebP 的高清连续纸张页面流，可上下滚动阅读。
- 页面图片采用视口附近加载、当前页前后轻量预加载和空闲后台小批量预加载策略；后台页图使用低优先级 eager 请求，减少首屏等待，同时让停留阅读时真正预热后续页面。
- 搜索索引直接来自 Typst 源文本，并用 Typst 查询一级标题所在页码。
- 使用 `data.js` 内嵌目录与索引数据，支持直接打开 `index.html`。

## 使用方法

在 `考研数学` 目录下重建电子书：

```bash
python3 ebook/scripts/build_index.py
```

打开网页：

```bash
open ebook/index.html
```

也可以启动本地静态服务：

```bash
python3 -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/ebook/index.html
```

## 输出文件

- `ebook/book-manifest.json`：电子书目录数据，包含正式章节和各章节内的大点子目录。
- `ebook/search-index.json`：基于 Typst 源文本生成的全文搜索索引。
- `ebook/data.js`：供静态网页直接读取的数据文件。
- `ebook/index.html`：电子书入口。
- `ebook/rendered-pages/`：由 Typst 自动渲染并压缩出的 WebP 高清页面图片。

## 日常更新流程

当某个章节 Typst 源文件更新后，重新执行：

```bash
python3 ebook/scripts/build_index.py
```

脚本会自动刷新目录、一级大点页码、搜索索引和对应 WebP 页面图片。缓存标记会记录 Typst 源文件、文件大小、修改时间、页数、图片格式和渲染 DPI；只有源文件或参数变化时才重新渲染页面。
